# Connect Four

Terminal-based Connect Four game built in Ruby following test-driven development principles and object-oriented architecture.

This project focuses on game state management, rule validation and modular software design while implementing the classic Connect Four gameplay experience.

## Features

- Turn-based Connect Four gameplay
- Win condition detection
- Horizontal, vertical and diagonal validation
- Input validation and error handling
- Object-oriented architecture
- Modular game logic
- Test-driven development workflow
- Terminal-based interface

## Tech Stack

- Ruby
- RSpec

## Installation

Clone the repository:

```bash
git clone https://github.com/bachatron/tdd_connect_four.git
cd tdd_connect_four
```

Install dependencies:

```bash
bundle install
```

Run the game:

```bash
ruby main.rb
```

Run tests:

```bash
rspec
```

## Project Structure

The project is separated into independent classes responsible for:

- Board management
- Player turns
- Move validation
- Win condition checking
- Game state handling
